# Decision — {{TITLE}}

Articles 30, 31. The compact format the owner reads. Lives on a tracked path (`docs/governance/decisions/`) or, if it contains security findings or forensics, in the private standard repository's `decisions/`.

| | |
|---|---|
| **Situation** | What happened / what is proposed, in two sentences. |
| **Evidence** | What we know, with paths, run ids, screenshots. What we do not know. |
| **Recommendation** | What should happen. |
| **Risk** | What could go wrong; which priority (Article 3) this serves when two collide. |
| **Validation** | What has already been tested and how; what is "unverified". |
| **Rollback** | How we recover, and whether data state is reversible. |
| **Models involved** | Builder · reviewer(s) · vendor of each. |
| **Decision required** | Approve / Reject / Modify — and the door: one-way or two-way. |
| **Decision** | (owner) · date |
