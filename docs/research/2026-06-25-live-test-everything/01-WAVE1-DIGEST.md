### [signup-onboarding] Per-route @Throttle on public signup is a costume — rate limit never fires (5/min not enforced; 600/min global is the real cap)
- **Where:** apps/api/src/onboarding/onboarding.controller.ts:23-31 (@Throttle{limit:5}); apps/api/src/app.module.ts:158-161 (unnamed ThrottlerModule.forRoot default limit:600) + 215-218 (APP_GUARD)
- **Repro:** curl -X POST https://api-production-39a1.up.railway.app/api/v1/signup -d '{"districtName":"Acme Coffee — Hartford","slug":"acme-hartford","adminEmail":"x@example.invalid","password":"abcd1234efgh","vertical":"K12"}' -H 'Content-Type: application/json' — fire it 8 times in a row.
- **Evidence:** LIVE: 8 consecutive valid-shape requests all returned 409 (reached business logic), ZERO returned 429. The decorator declares 5/min but @nestjs/throttler's named-throttler 'default' override does not bind to the UNNAMED forRoot config (app.module.ts:158 has no name key), so only the global 600/min applies. 600/min on an unauthenticated, account-creating endpoint = effectively unlimited abuse. Same broken pattern affects password-reset (3/hr) and invite-accept (5/min) — all the auth-abuse guards are non-functional.

## Synthesis — Executive Summary

The app is far more real than "costume" — signup, login, dashboard/fleet, screens/pairing, assets, the sports console, branding and the emergency core all work end-to-end on live prod. But money and AI are dark, several "shipped" features silently no-op, and security is propped on guessable secrets. Fix these first: (1) prod runs on guessable JWT/SESSION secrets — anyone who guesses them forges any session incl. SUPER_ADMIN; (2) Stripe webhook can't receive a single event (global express.json shadows rawBody) AND prod is on Stripe TEST keys — no money can ever be collected; (3) cross-location published assets get status APPROVED but playback only serves PUBLISHED — corporate-pushed content silently never displays; (4) the "Schedule a window"/group publish path writes inactive/per-screen schedules so playlists silently never play; (5) emergency SOS/broadcast overlays can't be cleared by all-clear. AI is 100% off (no platform key). Rate limiting is theater across signup/login/reset. Firefox signup strands users on a spinner. Tackle secrets + billing + the silent-no-op trio next.
