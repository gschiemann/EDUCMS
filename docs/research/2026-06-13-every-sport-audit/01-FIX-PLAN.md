## DOMAIN: config+api  (0×P0, 5×P1, 12×P2)
- **[P1] soccer / config** — Soccer half auto-advances at regulation — stoppage/added time is impossible with the clock running  `(apps/api/src/sports/sports.service.ts:2211)`
    fix: In sports.service.ts autoAdvanceExpiredClocks, for count-up sports do NOT auto-advance the segment at segMs — either (a) never auto-advance count-up (let the clock keep counting up past regulation and require the operator to advance the half), or (b) add the game's `addedTime` minutes to the expiry threshold (segMs + addedTime*60000) so the half only auto-rolls after added time. Pair with surfacing added time on the clock (see the board finding).
- **[P1] baseball / config** — Walk (4th ball) resets the count but never advances a runner to 1B — the diamond never lights on a walk  `(apps/api/src/sports/sports.service.ts:2470)`

- **[P1] volleyball / console** — Advancing to the next set never zeroes the point score — operator must manually reset both scores or the board shows a wrong (carried-over) score  `(apps/api/src/sports/sports.service.ts:2099-2156)`
    fix: In apps/api/src/sports/sports.service.ts setSegment(): when def.score is points-to-target with clock.type==='none' (volleyball/pickleball), on a forward segment advance auto-zero homeScore/awayScore (record a SCORE GameEvent for the undo rail). Best-in-industry: also auto-credit the set/game-won stat (homeSets/awaySets or homeGames/awayGames) to whichever side led the just-finished set. Pair with a one-tap 'End set → next set' macro in the console (apps/web/src/app/[schoolId]/sports/[gameId]/page.tsx near the segment +/- chips at line 1668-1687) that does reset+credit+setWin cue in one action.

    fix: Add a wrestling dual-meet model: team-points fields + per-bout/weight-class context (or a second LEADERBOARD-style team tally) in packages/api-types/src/sports.ts, surfaced on board/page.tsx; clarify match-points vs team-points so both can show.
