## How to use this folder
- **Folders are named `YYYY-MM-DD-<topic>`.** Each holds one session's reports + (usually) a `README`/`00-` synthesis.
- Read the `00-*`/`SYNTHESIS`/`REPORT` file first — it's the conclusion; the rest is supporting detail.
- These are **point-in-time** records. For current behavior, trust the code + the latest synthesis, not an old report.
