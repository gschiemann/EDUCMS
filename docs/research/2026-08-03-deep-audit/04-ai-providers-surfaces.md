## Findings

**[P2] Alt-text bypasses the S5 tier-separation hard-error — silent platform fallback on unreadable BYOK key** — `ai-alt-text.service.ts:257-260` catches BYOK decrypt failure with only a `logger.warn` and falls through to platform `OPENAI_API_KEY`/`ANTHROPIC_API_KEY` (:269-279). `AiService.resolveProviderKey` was hardened 2026-07-16 to throw `AI_KEY_UNREADABLE` on every spend path for exactly this case (`ai.service.ts:518-610`), but alt-text keeps its own divergent copy of key resolution (plus duplicated `bumpPlatformUsage`/`isPlatformCapExhausted`, :288-325). Impact: a tenant whose key broke (master-key rotation, corrupt blob) silently burns Tier-1 budget on every image upload with no operator signal — bounded by the 200/mo cap and audited, but it is precisely the "silent Tier-1 spend" S5 outlawed, and the checklist's "shared code, not divergent copies" bullet fails here for key resolution (error mapping IS shared). Fix sketch: have `AiAltTextService.resolveProvider` delegate to (or mirror) `resolveProviderKey` semantics — configured-but-unreadable → skip with audit reason `AI_KEY_UNREADABLE`, never platform fallback; dedupe the usage-counter copies. **NEW**

**[P3] Vision calls break temperature parity** — OpenAI (`ai-alt-text.service.ts:769-791`) and Anthropic (:851-883, and the second pair :938-961/:1075-1112) vision requests send no `temperature` (provider default 1.0); Google vision pins 0.7 (:809, :1014); all text paths pin 0.7 (`ai-providers.ts:441`). Impact: alt-text/design-reference output variance differs by provider; for deterministic captioning you'd want low temp everywhere. Fix: pin one explicit value (0.3–0.7) on all vision branches. **NEW**

**[P3] Economic-model doc vs code: platform free tier DOES serve Tier-2 actions** — CLAUDE.md ("sparkle should say 'Configure your AI provider' … not 'fall back to platform key'") conflicts with implemented behavior: a no-BYOK tenant runs sparkle/concierge/images on `ANTHROPIC_API_KEY` up to a 200/mo Canva-style cap (`ai.service.ts:405-418,784-799`), surfaced in UI + audit — deliberate per code comments, not silent. The Tier-1 spec's "≤50 calls lifetime" concierge budget is not implemented as such either (concierge is Tier-2, `ai.service.ts:1358`). Impact: future agents reading CLAUDE.md will "fix" correct code, or vice versa. Fix: update CLAUDE.md Economic Model to the shipped capped-free-tier design (or get Greg's ruling). **NEW** (behavior itself KNOWN/intentional)

**[P3] Platform `OPENAI_API_KEY` env var is load-bearing but undocumented** — alt-text prefers platform OpenAI over Anthropic (`ai-alt-text.service.ts:269-278`); CLAUDE.md's env table documents `ANTHROPIC_API_KEY` only. Impact: deploy configured per docs silently uses the more expensive Anthropic vision path. Fix: one row in the env table. **NEW**

**[P3] Stale CLAUDE.md numbers: "30/hr" cap and "claude-haiku-4-5 at 300 max_tokens ~$0.005/call"** — default hourly cap is 120 (`ai-hourly-cap.ts:51-54`, env `AI_HOURLY_CAP`); several surfaces use far larger budgets (designer boards 16k tokens, `ai-providers.ts:458-462`). Also `designer-prompt.ts:642` comment claims "caller sets a low temperature via the normal dispatch path" — dispatch exposes no temperature knob (pinned 0.7, `DispatchInput` :349-365). Cosmetic doc rot. **NEW**

**[P3] Audit rows are fire-and-forget everywhere** — every AI audit write ends `.catch(() => {})` (e.g. `ai.service.ts:963`, `ai-key.controller.ts:255,280`). A DB blip during an incident loses the forensic row while the generation succeeds. Deliberate availability tradeoff (documented); flagged for §16 since AI key-probing forensics depend on these rows. **KNOWN** (design comment on the lines)

**Verified-fixed spot-checks (no action):** F2 prompt-caching retraction pinned with specs (`ed0e42b3`); imagen→`gemini-3.1-flash-image` migration live with no dead fallback (`f825769b`, `ai.service.ts:4297-4320`); the 2026-06-09 dead-code bug where generate-time quota 402s were swallowed is fixed (`ai.service.ts:877-886` rethrows any `HttpException`); W0-03 dead models purged + alias-healed + CI-gated.
