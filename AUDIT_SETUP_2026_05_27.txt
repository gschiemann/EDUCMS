------------------------------------------------------------
ROOT CAUSE — single, dominant bug
------------------------------------------------------------

apps/web/src/app/ribbon/[gameId]/page.tsx had a short-circuit at line
807 (pre-fix) that DIVERTED EVERY GAME into "media-scroll mode" the
moment ANY ribbon slide OR any sponsor existed:

    if (def && ((data.ribbonSlides || []).filter(Boolean).length > 0
              || (data.sponsors || []).length > 0)) {
      return <RibbonMediaScroll ... />   // bypasses looks rotation
    }

In media-scroll mode the page renders ONLY:
  • the pinned score anchor (ScoreZone)
  • the slides+sponsors marquee
  • spotlight overlay (if set)
  • celebration cue overlay (if firing)

Every other Ribbon-content toggle the operator flipped in setup was
SILENTLY IGNORED:
  • Crowd messages (prompts)         — text in RibbonPanel
  • Player spotlights (roster)       — roster cards rotation
  • Game situation (situation)       — sport-specific live state
  • Slides toggle                    — slides still showed when off
  • Sponsors toggle                  — sponsors still showed when off
  • Game-clock toggle (clock)        — always rendered on anchor
  • Segment toggle (segment)         — always rendered on anchor

The "score and ribbon media play nothing else" report is the literal
visible output of this short-circuit.
