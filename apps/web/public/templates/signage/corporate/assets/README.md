# Corporate profile stock photographs

Four default stock portraits support the reusable People Team and All-Hands templates. They are sample profiles, not representations of actual North Star employees. Every portrait is an operator replaceable `data-imgslot`.

Downloaded 2026-10-10 from the regular Unsplash image CDN under the [Unsplash License](https://unsplash.com/license). Saved locally at 1000×1200 JPEG; no runtime hotlink or API call.
