ARC RIOT / DIRECTORY EDITOR

Paste from Excel or a CSV. Columns: Name, Location, Floor, Category. A matching header is optional. A quoted CSV can include commas inside names.

Pages grow automatically. Use “Start a new page” to create a deliberate page break. Keep names and locations together; text is never shortened with an ellipsis.

The image stays inside its centered frame. Palette changes preserve the selected layout.

Page duration is the stationary reading time. A transition is added after it. Continuous scrolling uses speed; per-page durations apply to paged modes. Reduced-motion preference replaces movement with static page changes.

Changes appear in the preview. Save a directory file to keep a portable copy.
