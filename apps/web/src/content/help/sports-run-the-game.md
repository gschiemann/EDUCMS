# Run the scoreboard during a game

The **Run game** tab is the live console. It's built so you can run the entire game without scrolling or switching tabs.

## Score

Each team has its score with quick buttons for that sport's point values — a football zone has **+1, +2, +3, +6**; basketball has **+1, +2, +3**. Tap to add; the **−** button corrects a mistake.

## Clock

For sports with a game clock:

- **Start / Stop** runs and pauses the clock.
- **Reset** sets it back to the period length.
- Tap the **clock readout** to type an exact time (`MM:SS`) — useful after a timeout or a correction.

The clock is an anchor: the server stores the reading and every screen counts locally from it, so the scoreboard, ribbon, and overlay all stay in sync to the same second.

## Period

Move the period forward or back with the segment control — "Quarter", "Period", "Inning", "Set", named for your sport.

## Sport-specific stats

Each sport shows the right controls for its situation:

- **Football** — a 1st/2nd/3rd/4th **down** selector, **type-in** fields for yards To Go and the Ball On (yard line), and a **Home / Away possession** toggle. Possession lights the football marker next to that team on the scoreboard.
- **Basketball** — team fouls, timeouts, and a possession toggle.
- **Baseball / softball** — a Ball / Strike tray with the live count and base runners.
- **Volleyball** — a serve toggle and set scores.

A simple rule runs throughout: wide-range numbers (the yard line, shots) are **type-in** — you never tap "+1" dozens of times. Small counts (timeouts, outs) use **+/−**. Whoever has the ball or the serve is a **Home / Away toggle**.

## Cues and celebrations

Tap **Cues** to fire a touchdown burst, a three-pointer, or your own custom celebration — see [Fire celebrations and custom cues](/help/sports-cues).
