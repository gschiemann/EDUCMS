# 网络与防火墙要求

屏幕只需要**能上网**。它们不必接入您的内部网络，也没有任何连接会*进入*您的网络。

## 简要说明

- **出站 HTTPS（TCP 443）**是唯一要求。无需入站连接、端口转发、VPN 或在防火墙上开口。
- VenueOS 播放器**不开放任何监听端口** —— 每个连接都由屏幕发起。
- 建议把屏幕放在与内部系统隔离的**访客或物联网网段**。
- 屏幕需要准确的时钟：请放行 **NTP（UDP 123）**或提供本地时间源。证书校验和排程都依赖它。

## 需要放行的目标（出站 TCP 443）

| 目标 | 用途 |
|---|---|
| `venue-os.app` | 管理后台和屏幕播放器应用 |
| `api-production-39a1.up.railway.app` | VenueOS 服务，包括与屏幕的实时连接（安全 WebSocket，`wss://`） |
| `bhdaxzfalaycfopvcopm.supabase.co` | 您的内容文件和播放器软件更新 |
| `github.com`、`*.githubusercontent.com` | Android 播放器软件更新（备用下载途径） |
| `fonts.googleapis.com`、`fonts.gstatic.com` | 许多设计模板使用的网页字体 |
| `api.open-meteo.com`、`geocoding-api.open-meteo.com`、`ipapi.co` | 仅用于天气组件 —— 本地天气预报，以及组件未设置位置时的大致城市 |
| `*.sentry.io` | 错误报告。可选：屏蔽后不影响播放 |
| 您自己的内容来源 | 仅当您在屏幕上添加网站、视频流、社交媒体或其他在线内容时 |

如果您的网络屏蔽 WebSocket，屏幕会自动改用指向同一服务的普通 HTTPS 请求 —— 内容和紧急警报照常送达，只是晚几秒。

## TLS 检查

请将上述目标排除在 SSL/TLS 检查之外。屏幕会校验服务器证书，不会通过其不信任证书的检查代理建立连接。

## 带宽与断网

- 内容只**下载一次**，按其指纹校验后保存在屏幕上。之后的流量主要是少量的状态检查和变更。
- 大视频分成可续传的小段下载，网络慢或中断后会从中断处继续。
- 断网时，屏幕继续播放已保存的内容，联网后自动补齐。正在显示紧急警报的屏幕会一直显示，直到收到解除警报。

## 后台用户

管理屏幕的员工只需一个现代浏览器，并能通过 HTTPS 访问 `venue-os.app` 和上面列出的 VenueOS 服务地址。电脑上无需安装任何软件。

## 集成

单点登录、收银系统菜单、社交媒体等集成都是**从 VenueOS 云端连接到服务商**。没有任何连接进入您的网络。

## 仍然无法连接？

请发送邮件至 support@venue-os.app，写明屏幕名称、屏幕上显示的内容，以及（如果知道）您使用的防火墙或网页过滤产品。我们会协助您的 IT 团队找到拦截的规则。
