# 登录、通行密钥与两步验证

请使用您的工作邮箱在 **venue-os.app/login** 登录。本页介绍首次登录、VenueOS 确认是您本人的几种方式，以及出现问题时如何重新登录。

## 登录流程

1. 输入您的工作邮箱，点按**继续**。
2. VenueOS 只显示适用于该地址的方式：密码输入框；如果您的组织使用单点登录，则显示**使用单点登录继续**（见[设置单点登录](/help/sso)）。
3. 如果您的账户启用了两步验证，接下来用通行密钥或验证码确认。

如果这台设备上已有您账户的通行密钥，可直接在第一个页面点按**使用通行密钥登录**——无需密码，也无需验证码。

密码旁边的**保持登录状态**可让您在该浏览器上保持登录最长 30 天；不勾选时，每次登录最长持续 12 小时。只在您自己的设备上勾选。修改密码会让您在其他所有设备上退出登录。

## 首次登录

开始方式取决于管理员如何添加您（管理员请参阅[邀请员工并分配角色](/help/invite-users)）。

### 通过邀请邮件

打开邀请邮件中的链接（7 天内有效）。设置一个至少 8 个字符的密码，再输入一次，然后点按 **Join workspace**。如果您的组织要求两步验证，VenueOS 会请您再登录一次并完成设置。

### 通过设置链接或初始密码

一次开设多个场所的组织会在确定使用者之前先创建账户，并附带临时邮箱和初始密码，或一次性设置链接。打开设置链接并点按**继续**，或者用收到的临时邮箱和初始密码登录。随后 VenueOS 会显示**完成账户设置**：

1. 在**你的工作邮箱**中输入您的邮箱，并在**再次输入你的邮箱**中再输入一次。请使用您能打开的邮箱：登录验证码和密码重置邮件都会发到这里，之后您无法自行更改。
2. 设置一个至少 8 个字符的**新密码**（不能与初始密码相同），并再次确认。
3. 点按**保存并继续**。
4. 如果 VenueOS 要求输入验证码，请打开刚发到该邮箱的邮件，输入 6 位验证码，然后点按**验证并完成**。验证码 10 分钟内有效，输错 5 次即作废。如果没有收到邮件，请先查看垃圾邮件文件夹，再点按**重新发送验证码**。邮箱填错了？点按**使用其他邮箱**。

设置链接只能使用一次，7 天后失效。如果提示链接已过期或已被使用，请向管理员索取新链接。如果您的账户必须使用两步验证，VenueOS 会直接带您用刚设置的邮箱完成设置。

### 通过单点登录

使用您组织自己的账户登录，无需另设 VenueOS 密码。

## 两步验证

启用两步验证后，仅凭密码无法登录：您还需要用只有您拥有的东西确认身份——通行密钥，或身份验证器应用中的验证码。

**谁必须使用。** 当超级管理员把组织设为**必须使用双重验证**（**设置 → 人员与访问 → 双重验证策略**）时，所有超级管理员、所有管理员以及所有有权发送紧急警报的人员，都必须先完成设置才能登录。管理员也可以在某人那一行点按**要求双重验证**，单独要求此人使用。任何人都可以在**设置 → 我的安全**中自行开启。

**必须使用时如何设置。** 输入密码后，登录页面会显示**设置双重验证**。请选择一种方式：

- **使用面容 ID、触控 ID 或安全密钥**——在这台设备上创建通行密钥，无需安装任何软件。
- **改用身份验证器应用**——用 Google Authenticator、Microsoft Authenticator、1Password 或 Authy 等应用扫描二维码（或手动输入显示的密钥），输入应用显示的 6 位验证码，然后点按**完成登录**。

接着保存您的备用码（见下文），并点按**已保存，继续**。

## 通行密钥

通行密钥让您用面容、指纹或设备 PIN 码登录，无需输入密码和验证码。这是最快的登录方式，而且无法被钓鱼网站骗取：通行密钥只在真正的 VenueOS 网址上有效。

| 设备 | 确认方式 |
|---|---|
| Mac | 触控 ID，或 Mac 的登录密码 |
| iPhone 或 iPad | 面容 ID 或触控 ID |
| Windows 电脑 | Windows Hello：面容、指纹或 PIN 码 |
| Android 手机 | 指纹、面容或屏幕锁定 |
| 安全密钥（USB 或 NFC） | 轻触密钥 |

保存在 iCloud 钥匙串（Apple 设备）或 Google 密码管理器中的通行密钥，也会出现在您登录同一账户的其他设备上。Windows Hello 通行密钥通常只保存在那台电脑上。每个账户最多可有 10 个通行密钥，建议在您使用的每台设备上各添加一个。

**添加通行密钥。** 登录后，VenueOS 可能会询问**下次使用面容 ID 或触控 ID登录？**（Windows 上为 Windows Hello）。点按写有您设备名称的按钮，例如**为这台 Mac 添加通行密钥**，然后按设备提示操作。点按**以后再说**会在以后再次询问；点按**在此设备上不再询问**则不再询问。您也可以随时打开**设置 → 我的安全**，找到**通行密钥**，点按**为这台……添加通行密钥**，确认密码后按提示操作。在同一列表中可以重命名或删除通行密钥；删除时需要输入密码。如果通行密钥是您的第一种验证方式，VenueOS 还会显示备用码——请务必保存。

**使用通行密钥登录。** 在第一个页面点按**使用通行密钥登录**，或在输入密码后点按**使用通行密钥**，然后在设备上确认。在电脑上，浏览器还可以显示二维码：用存有通行密钥的手机扫描即可（两台设备都需开启蓝牙）。

## 身份验证器应用与备用码

要使用身份验证器应用，请打开**设置 → 我的安全**，进入**两步验证**，点按**启用 2FA**。扫描二维码（或输入设置密钥），输入 6 位验证码，然后点按**验证并开启**。

**备用码。** 首次设置两步验证时，VenueOS 会显示 10 个备用码，只显示这一次。如果手机丢失或无法使用通行密钥，每个备用码可用于登录一次。请复制或下载后妥善保管：存入密码管理器，或打印后锁好。**重新生成备用码**（需要输入密码）会生成一组新的备用码，之前未使用的备用码随即失效。

如果不想再使用该应用，请点按**停用 2FA** 并确认密码。如果您的账户必须使用两步验证，VenueOS 不允许移除最后一种验证方式——请先添加通行密钥。

## 在新设备上登录

- **通行密钥会同步到这台设备**（iCloud 钥匙串或 Google 密码管理器）：点按**使用通行密钥登录**。
- **通行密钥在另一台设备上：** 输入邮箱和密码，点按**使用其他方式**，然后选择**输入身份验证器应用中的验证码**、**使用备用码**，或者（如有显示）**通过邮件发送验证码给我**——验证码会发到您的登录邮箱，只能使用一次，10 分钟内有效。
- **在手机上**，您还可能看到**在这台 iPhone 上设置通行密钥**（或 Android 手机）：VenueOS 会先通过邮件发送验证码，然后为这部手机开启面容 ID、触控 ID、指纹或屏幕锁定登录。
- **登录之后**，VenueOS 会提示为新设备添加通行密钥，下次只需轻点一下即可登录。

使用邮件验证码登录时，您还会收到一封“新登录”通知邮件，如果不是您本人操作，您会及时知道。密码重置后的 7 天内不提供邮件验证码——请改用通行密钥、身份验证器应用或备用码。

## 无法登录时

| 遇到的情况 | 处理方法 |
|---|---|
| 忘记密码 | 在输入密码的步骤点按**忘记密码？**，然后输入邮箱。重置链接 1 小时内有效。设置新密码后，您会在所有设备上退出登录，两步验证依然有效。 |
| “此邮箱的登录尝试次数过多” | 多次输错密码后，VenueOS 会放慢登录速度；15 分钟内输错 20 次后，该邮箱会被暂停登录 15 分钟——即使密码正确也一样。请稍候，或重置密码。 |
| 验证码输错次数过多 | 1 分钟内输错 5 次验证码后，请等待 5 分钟再试。 |
| 手机、通行密钥和备用码都丢失了 | 请比您角色更高的管理员打开**设置 → 人员与访问**，在您那一行点按**重置双重验证**。这会移除您的身份验证器应用和通行密钥，并让您退出登录。您的密码不变，下次登录时重新设置两步验证即可。 |
| 账户中的邮箱有误 | 管理员可以在**设置 → 人员与访问**中您那一行点按**更改邮箱**进行更正。 |
| 邀请链接或设置链接已过期或已被使用 | 请向管理员索取新链接。 |
| 您的组织使用单点登录 | 您的密码及相关规则由组织的身份提供商管理——请联系您的 IT 团队。 |
| 您的账户已被停用 | 只有管理员可以重新启用。 |

如果您的组织中没有人能为您重置登录方式（例如您是唯一的超级管理员），请用您的工作邮箱发送邮件至 support@venue-os.app。
