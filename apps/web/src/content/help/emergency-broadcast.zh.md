# 自定义消息与员工 SOS

**自定义消息**会把您自己的文字显示在屏幕上，例如“全体教职员请到主办公室集合”“今天下午 1:00 提前放学”“B 停车场已关闭”。它比封锁或火警／疏散等警报更轻量——警报会用该警报的内容替换屏幕上的一切。关于警报，请参阅[紧急系统概览](/help/emergency-system)。

## 打开自定义消息

自定义消息是**紧急**页面上的一张卡片——与警报按钮在同一个页面，因此无需另外寻找：

- **在手机上**，点按顶部的红色**紧急**按钮，然后点按**发送至**下方的**自定义消息**。
- **在电脑上**，点按侧边栏中的**紧急**，然后选择窗口底部的**自定义消息**。**设置 → 紧急**中也有一个**打开自定义消息**按钮。

所有能够发送的人都会看到它。此页面原来的地址（您的工作区地址后接 `/emergency/broadcast`）仍然有效——它会直接带您到这张卡片——因此旧书签或旧邮件依然可用。警报生效期间，仪表板上的红色横幅有一个**紧急控制台**按钮，可打开紧急页面。

## 发送自定义消息

1. 选择它应如何**显示**：**提示**或**严重**（下面说明两者的外观）。
2. 输入您的**消息**，最多 500 个字符。预览会显示它的显示效果。
3. 在**发送至**中保持**所有屏幕**，或点按**选择屏幕**来选择一个屏幕分组或特定的屏幕（见下一节）。
4. 选择**显示时长**：5、15、30 分钟或 1 小时。默认为 5 分钟。
5. 按住**长按 3 秒发送**，直到进度条填满。提前松开会取消，不会发送任何内容。使用键盘时，请按住空格键或回车键。

绿色提示会确认消息已发出，消息会出现在**当前在屏幕上**下方。如果发送失败，会出现红色提示：没有任何内容发出，请重试。发送后，**发送至**一行会恢复为**所有屏幕**，这样下一条消息就不会因疏忽而只发给较小的范围。

## 选择哪些屏幕

**所有屏幕**是默认选项：您当前所在位置的每一块屏幕——如果您在下设多个位置的机构中工作，还包括这些位置的每一块屏幕。若要发送给更少的屏幕，请点按**选择屏幕**。警报使用的是同一个选择器：

- 点按一个**分组**，即可发送到该屏幕分组。
- 逐个点按**屏幕**即可选择特定屏幕——可以选择任意多块。**搜索**可缩小列表，**全选**会选中列表中显示的所有屏幕，**已选择 3 块屏幕**会为您计数。点按**完成**确认。

双面显示屏的两面都会收到消息，无论您选择的是哪一面。只有您选择的屏幕会显示它；其他屏幕照常运行。机构管理员可以在同一条消息中选择不同位置的屏幕。

## 屏幕显示什么

| 您发送的 | 屏幕显示 |
|---|---|
| **提示** | 屏幕顶部的一条横幅，显示您的消息。原来正在播放的内容继续在下方播放——它会下移并缩小，以适应横幅下方的空间，因此横幅不会遮挡它——消息结束后再恢复原位。 |
| **严重** | 整个屏幕变红，边框闪烁，显示“**广播**”字样和您的消息。 |
| 员工 SOS | 整个屏幕：**员工 SOS**、发送者的邮箱和他们给出的位置。 |

以旧的**警告**级别发送的消息（2026-10-26 之前，或通过 API 发送）会显示为**提示**。文字会缩小以适应竖屏、条形屏和小型 LED 屏，而不会被截断。屏幕通过实时连接在几秒钟内收到消息；实时连接中断的屏幕会在下一次检查时获取，大约每 10 秒一次。

## 员工 SOS 与语音留言

员工 SOS 是员工发出的全屏求助，可以附带一段录制的语音留言。屏幕可以显示它，进行中的 SOS 也会像其他消息一样出现在**当前在屏幕上**下方——但目前无论在仪表板还是 `/panic` 上，都还没有发送 SOS 或录制语音留言的按钮。如今要用手机发出警报，请打开 `/panic`，登录后长按合适的警报；参阅[紧急系统概览](/help/emergency-system)。

`/panic` 顶部的**语音开**／**静音**开关只会让您的手机朗读警报状态，不会录制或发送任何内容。

## 消息持续多久，以及提前结束

| 消息 | 在屏幕上停留 |
|---|---|
| 自定义消息 | 您选择的时间：5、15、30 或 60 分钟（不更改则为 5 分钟） |
| 员工 SOS | 30 分钟 |

时间到后，屏幕会自动撤下消息。若要提前结束，请点按**当前在屏幕上**下方消息旁的**解除**——任何能够发送的人都可以解除。只要屏幕上有内容，该列表就显示在卡片顶部，因此**解除**是您最先看到的。解除发送到特定屏幕的消息，只会在这些屏幕上结束它；解除从机构发出的消息，也会在其下所有位置一并解除。屏幕会直接回到原来播放的内容——途中不会出现任何警报画面。如果页面提示解除失败，消息可能仍在屏幕上——请再次点按**解除**。

完整警报（封锁、疏散等）的结束方式不同：在仪表板上输入 **CLEAR** 并点按 **Terminate Emergency (All Clear)**，或在 `/panic` 上使用**长按发送解除警报**。

## 始终是真实的——请用演习来练习

自定义消息没有 **LIVE | DRILL** 开关：每条消息都是真实的，屏幕不会将其标记为演习，所以请不要用它来练习。若要演练，请从顶部栏的**紧急**按钮或 `/panic` 开始演习：把开关拨到 **DRILL**（每次打开时都默认为 **LIVE**），屏幕就会在“THIS IS A DRILL”横幅下显示您的演习内容。

## 谁可以发送

- **超级管理员**和**管理员**可以发送自定义消息。
- **编辑**只有在管理员为其开启了**紧急警报**权限后才能发送——参阅[委派紧急权限](/help/panic-delegation)。没有该权限时，发送会被拒绝，也不会显示这张卡片。
- **查看者**不能发送或解除。
- **解除**会显示给所有能够发送的人——与服务器应用的规则相同。
- **API 密钥**永远不能发送或解除消息。

## 审计日志记录什么

每次发送和每次解除都会向审计日志添加一条永久记录。管理员可从**设置 → 紧急 → 查看谁做了什么**打开审计日志，可以筛选，也可以导出为 CSV 文件。记录无法编辑或删除。

| 记录 | 记录的内容 |
|---|---|
| `BROADCAST_TEXT` | 谁在何时发送、严重程度、消息长度、时长以及去向——对于特定屏幕，则是您选择的确切屏幕、承载该消息的每个显示面、它们的名称和位置 |
| `MEDIA_ALERT` | 谁在何时发送、去向、严重程度、多少个媒体文件、是否带声音以及送达多少个位置（通过 API 发送；卡片发送的是文字） |
| `SOS_TRIGGER` | 谁在何时发送、他们输入的位置以及是否附带语音留言 |
| `CLEAR_EMERGENCY_MESSAGE` | 谁在何时结束了哪条消息；对于发送到特定屏幕的消息，还包括它在哪些确切的屏幕上被结束 |

日志只保存消息的长度，不保存其文字。警报和演习有各自的记录：`TRIGGER_EMERGENCY`、`CLEAR_EMERGENCY`、`TRIGGER_EMERGENCY_DRILL` 和 `CLEAR_EMERGENCY_DRILL`。
